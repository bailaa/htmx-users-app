Принцип работы. 

При открытии страницы htmx по hx-trigger="load" делает GET-запрос к https://dummyjson.com/users?limit=6&select=.... 
DummyJSON возвращает JSON, а не HTML, поэтому расширение client-side-templates передаёт ответ в шаблон Handlebars (handlebars-template="t").
Handlebars проходит по массиву users через {{#each users}} и формирует HTML-карточки, которые htmx вставляет в соседний div.out без перезагрузки страницы. 
Кнопка также позволяет повторить загрузку по клику.

htmx позволяет описать запрос и вставку результата прямо атрибутами в разметке — без собственного JavaScript и без серверной части. 
Handlebars нужен потому, что htmx сам по себе ждёт готовый HTML, а DummyJSON отдаёт JSON; шаблонизатор превращает JSON в HTML в браузере, 
умеет циклы и экранирует выводимые данные.
